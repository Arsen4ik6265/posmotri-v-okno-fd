# Посмотри в окно

Учебный проект, который я самостоятельно выполнил во время обучения в Яндекс Практикуме по техническому заданию.

## О проекте

«Посмотри в окно» — веб-приложение для поиска и просмотра видео из разных городов. Пользователь может выбрать город, время суток и посмотреть подходящие видеоролики.

## Что реализовано

* Поиск видео по городу и времени суток.
* Получение данных с сервера через API.
* Отображение карточек с видеороликами.
* Переключение между видео.
* Загрузка дополнительных результатов по кнопке «Показать ещё».
* Отображение загрузки и обработка ошибок.

## Технологии

HTML, CSS, JavaScript, Fetch API.

## Мой вклад

Самостоятельно работал над учебным проектом: реализовал взаимодействие с API, поиск и фильтрацию данных, отображение результатов и обработку действий пользователя.

В процессе работы получил практический опыт создания веб-интерфейсов и взаимодействия с внешними сервисами.

## Как запустить

1. Скачать или клонировать репозиторий.
2. Открыть файл index.html в браузере.
3. Ввести название города, выбрать время суток и нажать «Найти».

Для загрузки видео используется внешний учебный API Яндекс Практикума, поэтому его доступность влияет на работу приложения.
