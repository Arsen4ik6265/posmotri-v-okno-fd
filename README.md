#Посмотри в окно

Открыть работающую версию сайта

Учебный веб-проект, который я самостоятельно выполнил по техническому заданию во время обучения в Яндекс Практикуме. Позже проект был дополнен демонстрационной версией.

##О проекте

«Посмотри в окно» — приложение, в котором можно выбрать город, время суток и посмотреть соответствующий видеоролик.

В демонстрационной версии доступны 8 городов: Москва, Санкт-Петербург, Казань, Сочи, Токио, Нью-Йорк, Лондон и Париж.

Для каждого города предусмотрены три анимированные сцены: утро, день и ночь.

##Возможности

* Выбор города из списка.
* Выбор времени суток.
* Поиск по выбранным параметрам.
* Переключение между видеосценами.
* Просмотр видео.
* Адаптация интерфейса под мобильные устройства.

##Технологии

HTML, CSS, JavaScript, работа с DOM и Fetch API.

##История проекта

Изначально я самостоятельно разработал учебное приложение, которое получало видео через API Яндекс Практикума. Исходный JavaScript сохранён в scripts/script.js.

После того как учебный API стал недоступен, для портфолио была подготовлена дополнительная демонстрационная версия с помощью ИИ-инструментов. В ней используются локальные анимированные видеосцены.

Это стилизованные иллюстрации городов, а не реальные видеозаписи улиц.

##Запуск

Работающую демонстрационную версию можно открыть по ссылке в начале описания. Для локального запуска достаточно скачать репозиторий и открыть index.html в браузере.
